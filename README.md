# Galerie

Bildbetrachter und -bearbeiter für Windows (Arbeitstitel) – **in Planung**.

- Ordner als Bibliothek, Galerie als Kacheln (stufenlos) oder Liste
- Sortieren, Filtern und Gruppieren nach Aufnahmedatum, Ort (GPS), Name, Kamera und weiteren
  Metadaten; Volltextsuche
- Metadaten bearbeiten (einzeln und für viele Bilder), Stapelverarbeitung (Umbenennen,
  Zeit verschieben, Drehen, Konvertieren, Exportieren) mit Vorschau und Rückgängig
- Nicht-destruktive Bildbearbeitung
- Läuft vollständig offline, schützt Originale und abgeleitete Daten, Installation mit einem
  Doppelklick

Plan, Entscheidungen und offene Fragen: [docs/PLAN.md](docs/PLAN.md).
